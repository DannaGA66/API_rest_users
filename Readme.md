Implementación completa de una API REST con Spring Boot y Java, que permite consultar, guardar y eliminar objetos.
Utiliza Spring Data JPA para la persistencia y se conecta a una base de datos MySQL

Descripción:
Este proyecto es una API RESTful desarrollada con Spring Boot que expone endpoints HTTP para gestionar una entidad (User). Sigue una arquitectura en capas ) y utiliza JPA/Hibernate para mapear los objetos a tablas en MySQL.

Requisitos:
Java 17 o superior
Maven 3.8+ 
MySQL 8+ 
VS Code con la extensión Extension Pack for Java/IntelliJ IDEA

Cómo ejecutar:
./mvnw spring-boot:run
